a software meant to connect organizations and people naturally

Uses data from initial screening of person to come up with events that the person might want to go to. After the user goes to a certain amount of events, we can use an algorithm to show events the user is most likely to enjoy/go to, The app will also have a feature that lets the organizations and users have public and private event info. Behind the scenes, we will give the organization access to a network that lets them invite people who are closest to people the organization knows. 

This software should be advantages to two groups of users. The people and the organization.
